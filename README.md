Como hacerlo funcinar 

- `django_api/`: API en Django con mysql Crear la tabla con `schema.sql`y  poner la contraseña
  en `config/settings.py` instalar `pip install -r requirements.txt` y correr `python manage.py runserver`.
  para java
- `java_app/`: app de escritorio NetBeans. Abrir con el servidor corriendo y ejecutar `MainForm`.
