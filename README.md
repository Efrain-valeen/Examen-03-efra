# Registro de Estudiantes

- `django_api/`: API en Django con MySQL. Crear la tabla con `schema.sql`, poner la contraseña
  en `config/settings.py`, instalar con `pip install -r requirements.txt` y correr `python manage.py runserver`.
- `java_app/`: app de escritorio (NetBeans, Maven). Abrir con el servidor corriendo y ejecutar `MainForm`.
